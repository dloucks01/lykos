## 2. Build next (doc 28's remaining tier, in priority order)

### 2a. OptiMin — MaxSAT-optimal corpus minset (on top of `distill.py`)
`distill.greedy_minset` is a greedy set-cover; OptiMin (ISSTA'21) solves the minset **optimally** via
MaxSAT for a smaller, higher-yield seed set. Add an optional `distill.optimal_minset(coverage)` that
shells out to a bundled MaxSAT solver (EvalMaxSAT / RC2 in pysat) when present, else falls back to
the greedy path. Air-gap note: the solver is a single self-contained binary/wheel to vendor.
- Effort: low–medium (the encoding is small; the dependency is the only wrinkle).
- Files: `analyze/fuzz/distill.py` (+ a solver locator in `toolchain.py`/doctor).

### 2b. Auto-derive a grammar from the inferred format spec / mined tokens
`grammar.from_spec` already bridges the flat format spec to a flat grammar. Extend it so the grammar
engine fires **without an analyst-supplied grammar**: promote the inferred spec's repeated/nested
fields to recursive rules, and fold the `cmpdict` comparison-constants + string tokens into the
terminal alternatives. Then have `_structure_mutator` prefer an auto-grammar when the spec looks
recursive (length-prefixed containers, TLV). Closes the last manual step in grammar fuzzing.
- Effort: medium (spec→recursive-grammar heuristics are the work).
- Files: `analyze/fuzz/grammar.py`, `analyze/fuzz/stage.py`.

### 2c. Joern — heavier cross-language / data-flow variant backend beside weggli
weggli is C/C++ AST matching; Joern adds a **code property graph** with interprocedural data-flow,
covering Go/Rust/Java/JS and source→sink flows weggli's AST patterns can't express. Vendor the Joern
dist (JVM app, Apache-2.0), add `analyze/joern.py` mirroring `weggli.py` (locate → run a CPG query →
findings → `to_targets`), and register it in doctor. Note: heavy (JVM + hundreds of MB) — install-on
-demand like Ghidra. **Do NOT vendor CodeQL as a default** (its license forbids offline closed-source
analysis).
- Effort: medium (JVM shell-out + a starter query pack); reuse the weggli→targets bridge shape.

### 2d. Deeper Tier-3 items (defer until a target demands them)
From doc 28: **CBMC/ESBMC** bounded-model-checking as a candidate verifier (turn a heuristic finding
into a witness trace); **Frama-C/Eva or IKOS** sound abstract-interpretation bounds; **firmware
breadth** beyond Cortex-M (Greenhouse user-space service rehosting is the highest firmware ROI, then
interrupt/DMA modeling, Qiling/Icicle for exotic ISAs, Firmadyne/FirmAE full-system); **Nyx/what-the

RetroWrite) for compiler-speed coverage/stack-ASan; **libqasan** built from AFL++ qemu_mode for
shadow-memory heap depth beside the memoracle lanes.

## 4. Quick reference — the new capabilities

- **Directed fuzz with the whole loop** (auto weggli + block-distance steering + input-to-state dict):
  it runs inside the normal `directed` stage; disable weggli with `params.weggli=false`, or pass
  pre-mapped `params.weggli_targets`.
- **Binary N-day variant hunt:** `lykos bindiff <old> <new>` (which function changed), then
  `lykos variant-scan --ref <vuln-bin> --func <name> <corpus...>` (find unpatched copies).
- **Source variant analysis:** `lykos weggli-scan <src-dir> [--cpp] [--json]` (needs weggli on PATH).
- **Differential testing:** `lykos diff-test <progA> <progB> [...] [--mode stdin|arg|file]
  [--compare status|output] [--seed FILE]` — reports where implementations disagree.
- **Memory oracle:** valgrind classification is automatic in `root_cause` for stripped native
  crashes; the guard-page fuzz oracle turns on with `LYKOS_PRELOAD=/usr/lib/afl/libdislocator.so`.
- **Modules for programmatic use:** `analyze/fuzz/{cmpdict,blockdist,distill,grammar,differential}.py`,
  `analyze/{variant,weggli}.py`, `analyze/dynamic/memoracle.py`.
