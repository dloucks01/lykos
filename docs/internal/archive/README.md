# Archive — historical planning material

These are kept for provenance, not guidance. They describe the Phase-0 plan and the original
UI mock-up; both have been superseded by the shipped implementation and neither is maintained.

| | What it was |
|---|---|
| `tasks/` | Phase-0 ticket breakdown. The build status notes inside record what was actually delivered against each ticket, which is why they are worth keeping. |
| `prototype/console.html` | The original static UI mock-up. The shipped UI is `core/lykos/api/static/index.html`, which took its design tokens from here. |

For what the platform does **now**, read `README.md`, `docs/air-gap.md` and
`docs/23-airgap-install.md`. For what is still open, `docs/internal/20-open-work-backlog.md`.
