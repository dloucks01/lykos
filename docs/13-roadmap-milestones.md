## Phase 9 — Frontier (stretch, scoped)
> **PHASE 9 BUILD STATUS (started):** **L3 assisted template exploit synthesis (ret2win) delivered** — the analyst-in-the-loop control-flow-hijack track (doc 15's L3 ceiling), never push-button. The `build_exploit` stage takes a confirmed instruction-pointer-control overflow in a **no-PIE x86-64** binary, recovers the control offset (the L2 cyclic-pattern technique), locates an attacker-chosen **win** function (`poc/exploit.py`: an ELF-symbol-table parser that finds a suggestive local name — win/backdoor/give_shell/print_flag/… — or, when a call graph exists, a local function that calls system/execve; or an explicit `params.win_addr`/`win_name`), synthesises the classic **ret2win** payload (cyclic filler + the win address at the saved-return slot), and **confirms the hijack** by reaching that function under a debugger breakpoint. ## Team & realism

real product and treat 8–9 as substantial follow-on tracks (Phase 8 multi-binary/firmware is itself large —
rehosting is a research-grade effort). An MVP demoable slice is **Phases 0,1,4,5** end-to-end on one binary
class. Multi-binary starts cheaply in Phases 2/6 (cross-binary callgraph + taint) before Phase 8's heavy
